# vocabulary v1 — single-word mythic creatures.
#
# Sources, per the owner: Jabberwocky, Brian Froud, the Gremlins films, and
# folklore and mythology from wherever it is told. Creatures, not deities:
# a gremlin is named after something that lurks, meddles or tinkers.
#
# Rules for adding words:
#   - one word, lowercase, ASCII, no punctuation (the name doubles as a slug);
#   - a creature or kind, not a real person and not a sacred figure;
#   - fun to say out loud, and unmistakable in a sidebar.
#
# NEVER edit an existing line in place. A gremlin's name is rolled once and
# persisted, so changing a word here cannot rename anyone — but keeping the
# list append-only means v1 stays quotable as v1. Grow it by adding lines, or
# start names/v2.txt when the character of the list changes.
